# 使用ChatGPT自动化开发

## cali lite 0.5.0

基于 cali.so **tag v2.0** 与用户 fork 的组件结构迁移到 Halo 的原生 Thymeleaf 主题。卡片、文章详情、项目与订阅组件保留源层级和 utility class，复用对应编译样式；React／Sanity 数据与交互改接 Halo 和原生浏览器 API。

源码仓库：[trizomx/halo-cali-lite](https://github.com/trizomx/halo-cali-lite)。目标：**Halo >=2.27.0**。

- 全屏易读网格、明暗外观、毛玻璃顶部导航；加载完成后切换指示，连续滚动收起。
- 首页单头像滚动收缩；左侧文章卡片、右侧便签及邮件订阅，侧栏按源Resume展示项目开发日志。
- 统一有图／无图卡片、照片主色与生成色、原版分层渐变和模糊质感。
- 文章详情：源版三栏、分段入场、UFO加载反馈、H1–H6细刻度文章地图、阅读进度与代码复制。
- 独立照片页：仅此页面参考 cali.so main/v3 照片瀑布流，使用本主题完整内容宽度、原比例照片、黑色背景中的FLIP放大、照片正下方的拍摄参数及预览／原图切换；首页照片带单独保留。
- 项目页模板与首页共用项目设置，图标／简介／外链和鼠标跟随虚线效果。
- 首页和页脚两处订阅，支持现成订阅页链接或表单POST；未接服务不收集邮箱、不伪造成功。
- **8组、55项后台设置**，项目页下拉选择、项目列表编辑及上传图标，无需修改代码。
- 正式安装包和源码都附开发说明，没有测试文章、图片、依赖或密钥。

## 安装与配置

上传 [cali-lite-0.5.0.zip](releases/cali-lite-0.5.0.zip) 到 Halo Console → 主题并更新；若新设置和“照片”模板没有出现，点击“重载主题配置”。

内部身份 `theme-cali-lite`、Setting `theme-cali-lite-setting`、ConfigMap `theme-cali-lite-config` 保持不变，同身份更新保留设置。

项目页：新建并公开发布别名为 **projects** 的页面即可，普通默认模板也会自动显示项目卡片与导航。主题设置“项目展示 → 项目列表”添加项目；首页使用开发日志样式，支持可选起止日期，独立项目页保留ProjectCard网格。其他别名可在“手动指定项目页面”下拉选择一次。

订阅：在“邮件订阅”粘贴邮件服务提供的现成订阅页面地址最方便；高级方式可配置其原生HTML表单POST地址及邮箱字段。真正发送、存储、退订由该服务负责，主题没有内置邮件后台。

照片页：

1. 新建并公开发布别名为 **photos** 的页面，保留普通默认模板即可；已有 `/photos` 页面可直接沿用。
2. 主题设置 → **照片页面 → 我的照片** 上传照片并保存。页面和导航默认自动识别，不必重复选择模板和绑定。
3. 页面别名不同时，在“手动指定照片页面”下拉选一次。默认先看缩略预览，放大后可手动查看原图；其余照片设置保留。

已有 gallery.items 照片配置保留，不必重新上传。首页文章封面照片带仍由“首页内容”单独控制，照片页不再替换它。

页脚：主题设置 → **页脚 → 显示实际主题版本号** 默认开启，自动读取当前安装版本；原来的“页脚补充文字”保留，手写旧版本可以自行清空。

当前实站：[home-page.241029.xyz](https://home-page.241029.xyz/)。用户每次更新会同步该站，后续开发先检查此处；本轮未自动部署。

首页头像：先在 **Halo 用户资料**中上传头像，再在 **主题设置 → 背景与导航 → 首页展示的博主账号** 选择该用户。首页大头像与页头小头像同步；多用户站点固定展示所选账号。留空或账号无头像时兼容站点Logo。

关于：新建并公开发布别名为 **about** 的页面，直接在页面编辑器维护正文，导航自动出现；其他别名可在“关于页面”手动指定。原简介弹窗已移除。

顶部导航已移除“分类”，分类页面和文章分类仍保留。站点标题、Logo、favicon和文章条数继续使用 Halo 系统设置。完整操作见 [开发说明](docs/开发说明.md)。

## 开发与交付

开始前必读 [AGENTS.md](AGENTS.md)、[开发说明](docs/开发说明.md) 和 [源码迁移对照](docs/源码迁移对照.md)。仅约束本项目。现有组件限定 tag v2.0；用户明确授权仅独立照片页和文章地图参考 main/v3，固定提交与来源见 `src/photos/sources.json`、`src/article-map/sources.json`；来源与许可边界见 [SOURCE-NOTICES](SOURCE-NOTICES.md)。

```text
src/cali/       源组件迁移源码、规则快照、来源哈希
src/photos/     独立照片页的v3参考快照、MIT声明与哈希
src/article-map/ 文章地图的v3参考快照及来源哈希
scripts/        源样式抽取与生成工具
templates/      Halo外壳；source组件、文章页和资源部分为生成文件
i18n/           默认消息
docs/           操作、迁移及验证说明
settings.yaml   8组主题设置
theme.yaml      身份、兼容与项目／照片／关于自定义模板
```

无需npm、React或原项目云服务。运行：

```bash
python3 package.py
```

先从 `src/cali/` 构建，再在 `dist/` 生成安装ZIP、源码ZIP和已解压源码目录。带Generated标记的文件禁止直接编辑。安装包只含运行文件及文档；源码包另含构建源码、开发约定和当前安装包。

本版完成720次本地Spring／Thymeleaf渲染，覆盖真实可见性枚举、自动／手动独立页面与多用户头像；原有导航、头像、取色、正文及原图策略检查通过。已通过真实浏览器检查黑色放大、参数位于照片下方、原图按钮、关闭回焦、关于页和导航。本地检查不代替完整Halo安装与真实附件服务验收；本轮未自动上传。
