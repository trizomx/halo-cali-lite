卡片两行标题和无图占位是用户明确要求，原源码并没有同样的强制等高约束。当前信息区为132px/130px；它是基于源行高的适配，不能宣称这是原站所有内容下的固定高度。

## 动效参数

源组件以 Framer Motion spring 实现；当前用单位质量、120Hz步长积分并生成 Web Animations 帧。最终帧归一到1，不支持时保持静态可读。

| 元素 | 初始状态 | stiffness / damping | 延迟 |
| --- | --- | --- | --- |
| 封面 | opacity0、scale.96、y10 | 120 / 20 | 0 |
| 日期分类 | opacity0、y10 | 150 / 20 | .1秒 |
| 标题 | opacity0、y8 | 150 / 30 | .2秒 |
| 摘要 | opacity0、y8 | 150 / 20 | .23秒 |
| 统计 | opacity0、y5 | 150 / 20 | .255秒 |
| 目录条目 | opacity0、y5、blur8 | 150 / 20 | .255秒 + 序号×.08秒 |

数值迁移保留了源行为意图；求解器、浏览器排版和原 Framer Motion 渲染不同，未宣称逐帧一致。后台可以关闭入场和加载动画，访客减少动态效果设置优先。

## 保留的 Halo 适配

- 所有文章、分类、标签、访问数来自 Halo；不搬运源站个人内容，不伪造数据。
- 站点信息依旧使用 Halo 系统设置；新增后台配置只控制主题栏目、外观和交互，不另造Logo/SEO/注入入口。
- 原生 `<a>` 导航，沿用已完成的头像、滚动页头和加载后导航指示。没有全站React路由或原站云服务。
- 首页便签为本主题已有栏目，按用户要求保留；两处邮件订阅提供界面和接入方式，实际发送由真实邮件服务负责。
- SOURCE-NOTICES 中区分本主题MIT适配、TailwindMIT与原组件来源；不把第三方代码一概宣称为原创。

## 0.2.1 复核补充

- `sanity/queries.ts → metadata.palette.dominant → BlogPostCard` 是源颜色链路，新增对应查询／schema的双副本SHA256记录。
- CSS抽取须包含源 `:after,:before{--tw-content:""}`，不能只提取class规则。伪元素必须位于函数选择器外，卡片覆盖／模糊层才会生成。
- 移除适配器的额外信息区background-color，避免与原bg-blend-overlay叠加染色；源组件原有before/after规则不做反色重写。
- 本地Canvas选择整图占比最大的量化色，删除饱和度加权；仍不是Sanity内部算法的逐字节移植。
- 首页项目复用源ProjectCard，在右侧单列展示；不再复制一份底部项目模块。完整项目页保持原网格。
